# LeetCodeFake

## Purpose

Build a learning-oriented online judge system and use each phase to understand the engineering process behind it: process execution, isolation, timeout, output limits, concurrency, Docker lifecycle, progress tracking, and system evolution.

## Current focus

Phase 5 — Judge Worker evolution from a minimal external-process runner toward a safer execution pipeline.

## Learning method

For each meaningful change, record:

- the concrete problem;
- the smallest approach that exposed the next problem;
- approaches tried and rejected;
- the chosen design and its trade-offs;
- evidence and verification;
- a reusable engineering lesson;
- a possible LinkedIn story.
