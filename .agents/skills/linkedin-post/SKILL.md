# LinkedIn post

Read the source learning note first. Do not add facts that are absent from it.

Produce:

1. Core insight in one sentence.
2. Recommended post draft, 600-1,200 words maximum unless the user asks otherwise.
3. Short version, 150-300 words.
4. Three hook options.
5. One practical takeaway.
6. Suggested hashtags, maximum five.

Recommended structure: concrete situation -> failed or insufficient first approach -> key insight -> trade-off -> current outcome -> takeaway. Use first person, plain language, and specific technical detail. Avoid inflated claims, fake certainty, and generic "keep learning" conclusions. Save drafts under `project/<project>/linkedin/` only when the user asks to save them.
