| 2026-09-02 | DSS_Song_Ray | [Crawler HTTP audit log: retention + unhealthy-source detection](SESSION-2026-09-02-DSS_Song_Ray-crawler-http-audit-log.md) | Added `crawler_http_log` table (FK cascade to `crawler_run_log`) plus an `AsyncLocalStorage`-based `loggedFetch()` wrapper capturing every crawler HTTP request/response with header/body redaction and truncation, wired into `crawler.scheduler.ts`'s `runAdapter` via `httpLogContext.run(...)`. | 2026-08-28 | DSS_Song_Ray | [Realtime hydro crawler Phase 6: admin crawler status card](SESSION-2026-08-28-DSS_Song_Ray-realtime-hydro-crawler-phase6-admin-status-card.md) | Built `GET /admin/crawler-status` (`CrawlerRunLogService.latestPerSource()` using Postgres `DISTINCT ON` for latest-run-per-source + a `GROUP BY` 24h failure count, merged against the `CRAWLER_ADAPTERS` DI list so never-run sources still appear) and a read-only `AdminCrawlerStatusCard`. No cron-parser dependency added — a 2-pattern regex estimator covers the only cron shapes the codebase actually produces. |

| 2026-08-26 | forecast-overview-redesign | [Forecast Overview dashboard: worktree state mismatch + a likely NestJS route-shadowing bug](SESSION-2026-08-26-forecast-overview-redesign-nestjs-route-order-worktree-mismatch.md) | Built a full-stack Forecast Overview dashboard (7 new tables/entities, service methods, routes, plus a 14-file Recharts frontend).
