# Mind map learning

Create a Mermaid `mindmap` document under `project/<project>/mindmaps/`.

Required branches:

- Project / phase
- Original problem
- Constraints
- Approaches tried
- Decision points
- Trade-offs
- Evidence / verification
- General lessons
- Open questions

Keep nodes short. Prefer causal relationships and evolution over a flat topic list. Mark unverified items with `(inferred)` or `(not verified)`.
